Das ganze Snippet

<!-- Platzhalter im Checkout -->
<div data-shlep
     data-key="pk_live_deinkey"
     data-from="47.3769,8.5417"  // Verkäufer
     data-to="47.5001,8.7501"    // Käufer
     data-size="large"
     data-value="450"></div>

<!-- einmal pro Seite -->
<script src="https://shlep.ch/shlep-widget.js" async></script>

Mehr braucht es nicht. Das Widget holt den Preis, prüft die Verfügbarkeit auf der Strecke und verlinkt die Käuferin direkt in Shlep — mit vorausgefüllter Lieferung.

Events shlep:quote und shlep:select für dein Tracking. Sprache via data-lang (DE/EN). SPA? Shlep.refresh().

Ist unsere API kurz nicht erreichbar, rendert das Widget einen Preis-Schätzwert statt eines Fehlers — euer Checkout bricht nie.

Endpoint

Wenn ihr lieber selbst rendert.
